NIMBUS BROWSER — setup
1. Install Node.js (https://nodejs.org) — one time.
2. Unzip this folder, open a terminal inside it.
3. Run:   npm install
4. Run:   npm start        (launches Nimbus)
5. Optional installer:  npm run build   (creates an .exe/.dmg/.AppImage in /dist)

Shortcuts: Ctrl+T new tab, Ctrl+W close tab, Ctrl+L focus address bar.

NO-SETUP OPTION (GitHub builds it for you)
1. Create a free repo at github.com and upload everything in this folder
   (include the hidden .github folder).
2. Open the repo's Actions tab, wait for "Build Nimbus" to finish (~5 min).
3. Open the finished run and download your installer under Artifacts.
